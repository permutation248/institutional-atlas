# 覆盖说明 · 2026-10-24

## v0.3 当前口径：组织世界模型

项目名称改为 **组织世界模型**。本轮以官方全量名录扩展总览，保留人工研究档案中的职责、治理、从属与金融机制。默认入口为全部组织总览；地图作为独立入口与组织选择联动。有目录记录但没有位置的组织仍属于总览，地图不会给它猜测坐标。

本次合并后为 **12,299 条组织记录、101 条正式结构关系、5,704 个地图位置、35 条金融机制、14 条官方事件**。其中 **143 份研究档案**，12,156 条仅为目录记录；负责人有来源的研究档案 **56/143（39.2%）**，不能将其推广到全目录。相对 v0.2 增加 12,167 条组织记录、11 条结构边和17条金融机制。

最新统计以 `dist/coverage.json` 和 `dist/atlas.json` 的 `metadata.catalogs` 为准：目录文件的原始行数、排除数、同名合并数、匹配人工档案数和新增目录数分别记录。**原始证券数、学校数、人工档案数与去重后的组织条目数不是同一种计数。** 下方 v0.2 表格是保留的历史基线，不能当作 v0.3 当前总量。

目录覆盖不代表深度研究覆盖。新目录记录采用 `record_kind: directory`、`verification_status: unverified`；当前负责人、治理、职责、财务、控制关系和实际交易没有逐项证据就保持空。与既有档案匹配时保留已研究字段和来源身份，不因某校获拨款或某企业上市而生成控制边。目录原始父级字段保存在来源资料中，不自动转成现行强关系。

跨目录身份目前额外人工解决 **1 组**：USA.gov 的 `usagov-1066` 与 IPEDS 的 `ipeds-197036` 均指向西点美国军事学院，名称、官网和机构性质一致。构建保留 IPEDS 主身份、校园坐标与分类，合并两个官方登记标识和来源；原 USA.gov ID 保留为别名。具体对照及两份官方证据在 `data/catalog-links.json`，不进行自动网站或名称相似匹配。其余跨目录重叠仍可能存在，合并后条目数不等于全球唯一法人数量。

IPEDS 提供 5,630 个来源校园点；76 个无有效坐标的教学机构留在总览。新政府和上市发行人目录没有批量核验的总部坐标，不能用华盛顿、纽约、交易所或上级总部填充。已研究档案已有的位置继续保留，目录坐标用于补齐缺失而不覆盖已有核验位置。

金融机制是独立证据层。美联储、财政部、银行体系、资本市场、大学与企业之间的制度路径必须区分现金支付、信用创造、资产交易、财政授权和政策指令；名录扩展没有生成任何虚构金额或实际交易。源于原始网站的机关描述、历史名称和证券名称保持其来源口径。

数据来源均保留本地快照与 SHA-256；构建验证本地内容和模式，不执行在线事实核验。采集日是 2026-10-24，IPEDS 源年度和证券文件生成时间独立显示。SEC 全量目录返回 403 时使用 Nasdaq 官方公开目录，没有绕过访问限制。目录标题、来源日期和范围在界面与导出数据中保留。

详细方法：[教育机构目录](CATALOG_COLLEGES.md)、[上市发行人目录](CATALOG_COMPANIES.md)、[政府及公共机构目录](CATALOG_GOVERNMENT.md)及各导入器。未知机构位置、治理、负责人和财务数值会继续作为下一轮研究任务；“系统收集已有官方目录”不等于“世界模型已完整”。

本次 v0.3 验收：95 项 Python 测试、17 项前端契约测试通过；Chrome 本地 HTTP 页面验证总览光点选择、AAPL 搜索、West Point 定位、3,877 个学位机构筛选、三分支并立、5,704 个地图位置、金融图与 390px 窄屏布局，未捕获控制台错误。测试尺寸覆盖 1440px 与 390px，结束后恢复浏览器原尺寸。生成页面内嵌数据、样式与脚本；自动化浏览器仅允许 HTTP(S)，因此没有执行 `file://` 直开验收。

## 明确缺口

39 个节点没有地图位置，其中既有制度性容器，也有尚未核验的实际组织。没有借用其上级坐标。27 个档案本轮沿用 2026-10-19 的局部研究、2 个沿用原始记录；103 个在 2026-10-24 局部复核。

尚未收录各州和地方政府、全国所有法院与分支行、全部企业子公司、所有大学、各部门完整第二层/更深目录。负责人、人员规模、预算／支出／收入仍不完整；结构化金额目前为 0，未来要用年度、会计口径和原文逐项引入。
