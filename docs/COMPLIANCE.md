# 开源数据与合规边界

本项目开发和发布时，应根据所在地及实际用户地区适用的法律重新评估。本文件是工程数据处理底线，**不是法律意见**。

1. **数据合法性**：第一版仅处理美国官方已公开、许可允许相应用途的数据；明确保存来源、时间、许可情况。
2. **接口许可**：遵循 API key、速率限制、访问条款；不要规避反爬、登录或付费限制；禁止使用 SAM.gov FOUO 数据重建公开完整组织图。
3. **个人信息最小化**：只录入与组织职责直接相关的公开职业任职信息。排除住宅地址、私人联系方式、家庭关系、私人资产等。
4. **发布节制**：源数据页面能访问，不代表整库可再分发；下载副本前检查数据集许可证、来源机构政策及第三方版权。
5. **事实优先**：每条边有证据；组织评价与决策分析不得构成无证据的诽谤或确定性动机推断。
6. **地理与法律边界**：美国联邦体系不能与中国行政层级生硬类比；州与市间的法定关系需按当地法律单独取证。
7. **部署独立评估**：公开 GitHub 和在中国大陆服务器运营网站适用的手续可能不同；如有收费、公众 AI 问答或新闻类服务，另行评估。
8. **变更与纠错**：保留旧版、时间戳及冲突证据；收到正确且有依据的更正应及时处理。
